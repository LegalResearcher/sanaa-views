# Sanaa Views

يسحب منشورات قناة `@SanaaPressAgency` ويعالج روابطها مباشرة عبر workflow مستقل، دون المرور بطابور Other.
جدولة Supabase الحالية متوقفة. عند تفعيلها ستستدعي `run-standalone.yml` عبر `workflow_dispatch` كل 35 دقيقة (يُفحص الاستحقاق كل دقيقة لضمان الفاصل الحقيقي).

## الإعداد
1. أضف بيانات الدخول: Settings > Secrets and variables > Actions > New repository secret
   - `SITE_USERNAME_1` و`SITE_PASSWORD_1` — بيانات الحساب الأول
   - `SITE_USERNAME_2` و`SITE_PASSWORD_2` — بيانات الحساب الثاني
   - `SITE_USERNAME_3` و`SITE_PASSWORD_3` — بيانات الحساب الثالث
   - `SITE_USERNAME_4` و`SITE_PASSWORD_4` — بيانات الحساب الرابع
   - `SITE_USERNAME_5` و`SITE_PASSWORD_5` — بيانات الحساب الخامس
2. في Supabase Vault أضف سر GitHub باسم `github_actions_token`، ويجب أن يملك صلاحية تشغيل Actions للمستودع.
3. تشغيل مباشر يدوي: تبويب Actions > Sanaa Views Standalone > Run workflow. تبقى workflows طابور Other منفصلة.

لا يمكن التحقق من وجود أسرار Actions في إعدادات المستودع من بيئة التطوير الحالية؛ يلزم التأكد من إضافة الأسرار العشرة بالأسماء أعلاه داخل إعدادات المستودع. لا تُحفظ قيمها أو تُطبع.

## كيف يعمل
- في كل تشغيل، تُقدّم الروابط الجديدة أولاً ثم تُضاف الدفعة السابقة فقط، بترتيب الأقدم فالأحدث.
- تُسجل الروابط المكتشفة لتجنّب إدخالها ثانيةً كروابط جديدة.
- يرسل كل تشغيل حتى خمسة طلبات كحد أقصى.
- لا يُرسل الرابط أكثر من مرة للحساب نفسه؛ يُحفظ سجل الحسابات لكل رابط في `state/link_account_history.json`.
- يُسجل الحساب للرابط قبل الإرسال حتى لا يتكرر الطلب عند انقطاع التشغيل بعد الإرسال.
- إعادة المحاولة اليدوية تستخدم عدادات النجاح والإخفاق نفسها، وترفض الرابط بعد بلوغ خمسة نجاحات، أو إذا كان مكتملًا في السجل القديم، أو تخطى ثلاث إخفاقات.
- يختار كل تشغيل حسابًا واحدًا بالتتابع `1 → 2 → 3 → 4 → 5 → 1`، ويستخدمه طوال التشغيل. المؤشر محفوظ في `state/account_rotation.json`.
- عند الانتقال من الإصدار السابق، تُعامل روابط `state/done_links.txt` كسجل إنجاز تاريخي: لا يعاد تنفيذها ولا يُعدّل الملف أو تُحتسب لها نجاحات تاريخية غير معروفة. يبدأ العد الجديد للروابط غير المكتملة والجديدة فقط.
- يتم تسجيل الدخول إلى الموقع وإرسال الطلب من خلال نموذج المتصفح، مع النقر البرمجي على زر التأكيد لتجاوز العناصر العائمة.

## تصفير الحالة
احذف ملفات الحالة داخل مجلد `state/` (ما عدا `.gitkeep`) لبدء المعالجة من الصفر.

## ملاحظة
بيانات الدخول لا تُكتب في أي ملف. المستودع عام، فملفات `state/` مرئية للجميع؛ ملف الدوران لا يحتوي إلا على رقم الحساب التالي.
